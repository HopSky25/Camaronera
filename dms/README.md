# DMS

Gestión documental para Odoo 19, a partir de [OCA/dms](https://github.com/OCA/dms).

Se migró desde la rama 18.0 de la OCA cuando su 19.0 todavía estaba vacía.
Después la OCA publicó su propia migración, así que las dos historias han
divergido sin ancestro común: este código se mantiene aquí, no se sincroniza
con la OCA.
