# Recursos de terceros

Los archivos XSD en `l10n_ec_sri_community/schemas` se descargaron de las fuentes oficiales identificadas en `SOURCES.json`. Los XSD del SRI se mantienen sin modificar y pertenecen al Servicio de Rentas Internas. El esquema `xmldsig-core-schema.xsd` pertenece a W3C y contiene su aviso de licencia original. No se incluye código de módulos Odoo Enterprise.

El código de este módulo usa las APIs públicas de Odoo Community 19.0. Los enlaces al código Odoo se proporcionan como referencia de compatibilidad.
