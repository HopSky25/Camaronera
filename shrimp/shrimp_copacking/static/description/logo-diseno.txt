Criterio visual

La caja distingue el servicio de empaque; la silueta de camarón conecta con el marketplace. Se usaron los PNG que el código de Odoo carga como logos; algunos SVG en verificadoras contienen una versión anterior del marketplace.

Prompt final
Use case: logo-brand.
Asset type: production horizontal transparent PNG logo for the Odoo website "CamaronMarket Empaque".
Primary request: Design one polished new sister-brand logo for shrimp co-packing, matching the visual family of the two local reference logos.
Input images: Image 1 is CamaronMarket marketplace logo, style reference only; Image 2 is Verimar verification logo, style reference only. Do not alter either reference. Their PNG versions are the real deployed logos; match these rather than obsolete SVG concepts.
Brand context: Ecuadorian shrimp ecosystem. Copacking plants package other companies' shrimp, reconcile incoming/outgoing pounds and record traceability. Existing official site name is CamaronMarket Empaque.
Composition: one horizontal lockup on genuine transparent background, approx 3:1 canvas, optically balanced, close usable margins. Symbol on left, wordmark on right, descriptor underneath wordmark. One logo only, no presentation board.
Symbol: simple bold geometric packing carton/cube, integrated with a recognizable simplified curled shrimp motif in negative space or clean teal silhouette. Convey packaging and traceability with a strong silhouette. Avoid excessive details, decorative arrows, checkmarks, shields, leaves, factory scenery or realistic shrimp. Shape should be legible at small sizes.
Typography: Match reference CamaronMarket's bold rounded lowercase sans serif. Exact main text "camaronmarket" with "camaron" deep navy #123E5C and "market" teal #14A0B0. Below, exact text "EMPAQUE · CO-PACKING" in uppercase, moderately spaced letters, slate #5A6B74, larger and more readable than reference's small slogan. This descriptor identifies the official site as CamaronMarket Empaque. No other words.
Palette: navy #123E5C, teal #14A0B0, restrained aqua-blue transition only within the symbol, akin to the references. Crisp flat vector-like finish, clean contours, no textures, photorealism, shadows, bevels or mockups. All external background fully transparent, preserve alpha. No watermark.
